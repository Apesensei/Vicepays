# Vice Pays

A neon-Miami slot game demo, playable in the browser: **https://apesensei.github.io/Vicepays/**

- 6x5 grid; 8 or more of a symbol anywhere pays; winning symbols drop away and new ones fall in.
- Heat signs (2x to 100x) multiply a winning spin. Wins in a row light the siren meter.
- Random events: drive-by wilds, symbol upgrade, monitor glitch.
- 4 police lights start **The Getaway**: 15 free spins with a Total Heat multiplier that never resets.
- Rounds are dealt from a fixed, weighted set (return to player 96.30%, max win 10,000x), built to Stake Engine's math rules.

Play money only. No real wagering. A portfolio piece, not a released game.

Art generated with Gemini and Google Flow; music from Google Flow Music. Code is plain HTML, CSS and JavaScript with no build step.
